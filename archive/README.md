# Stellarch archive-all

Complete dump of images generated for Stellarch that could still be recovered from this workspace.

## Layout
- `portraits-roster-01/` — full A/B roster portraits (2026-11-23)
- `batch-2026-11-24/` — Gallery CGs, ships, big-day scenes
- `gallery-cgs-png/` — full PNG gallery exports (may overlap batch)
- `portrait-redos/` — 8 redos (blade/choir/cartographer/thessaly)
- `reworks-v1/` — 10 reworks (Lyra, Neriss, Vy'rrakh, Ossa, Pip A+B)
- `references/` — reference sheets used for generation
- `other/` — previews / misc
- `MANIFEST.csv` — file name, date made, brief item, status
